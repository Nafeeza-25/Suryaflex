**# AI Website Development Workflow**



**When building or redesigning websites, use the installed skills when relevant.**



**## Design**



**Use `ui-ux-pro-max` for:**

**- design system**

**- colors**

**- typography**

**- layout patterns**

**- UX decisions**



**Use `design-taste-frontend` for:**

**- visual quality**

**- hierarchy**

**- spacing**

**- composition**

**- motion**

**- avoiding generic AI-looking websites**



**## Image / Screenshot References**



**If I provide a screenshot, mockup, image, or website reference:**



**Use `image-to-code`.**



**Treat the reference as the main visual source of truth.**



**Analyze:**

**- layout**

**- typography**

**- spacing**

**- colors**

**- buttons**

**- images**

**- sections**

**- responsiveness**



**Then implement it faithfully.**



**## Implementation**



**Use the existing project's framework and conventions.**



**Build reusable components.**



**Make the website responsive for:**

**- mobile**

**- tablet**

**- laptop**

**- desktop**



**Avoid:**

**- unnecessary cards**

**- excessive rounded boxes**

**- excessive pills**

**- random gradients**

**- clutter**

**- repetitive AI-looking layouts**



**## Final Review**



**After implementation, use `web-design-guidelines`.**



**Check:**

**- accessibility**

**- responsive behavior**

**- semantics**

**- keyboard navigation**

**- forms**

**- focus states**

**- readability**

**- interactions**



**Fix important issues.**



**## Browser Testing**



**Use `playwright-cli` after implementation.**



**Test approximately:**



**- 375px mobile**

**- 768px tablet**

**- 1024px laptop**

**- 1440px desktop**



**Check:**

**- navigation**

**- buttons**

**- forms**

**- overflow**

**- broken layouts**

**- text wrapping**

**- console errors**

**- failed requests**



**If problems are found:**



**inspect → fix → test again.**



**Do not consider the website finished just because it compiles.**
